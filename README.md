# 🍳 Puesto de Supervivencia

Juego 2D en el navegador: eres el dueño de un puesto de comida. Cocina para los clientes, gana dinero, compra ingredientes y mejoras... y no olvides comer tú también para sobrevivir.

**Jugar:** https://barbatjuan.github.io/puesto-de-supervivencia/

## Características
- Cocina, sirve clientes, compra recetas (incluido el ramen 🍜) y mejoras.
- Hambre y salud: cómete tus propios platos para sobrevivir.
- Depósito oscuro con cajas donde a veces hay ingredientes básicos.
- Lobby con tienda de clases (Principiante, Sazonador, Chef, Maestro) pagadas con tokens de comida.
- Multijugador cooperativo hasta 4 jugadores (P2P con PeerJS): uno crea la sala y comparte el código.

## Controles
WASD / flechas para moverse · E usar · mantener E buscar en cajas · 1-5 elegir plato · F comer · X tirar · Esc cerrar menú
